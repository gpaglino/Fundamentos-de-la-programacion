## Descripción

Este proyecto consiste en el desarrollo de un **e-commerce básico** utilizando **PHP, HTML y CSS** como tecnologías principales.

## Acceso al panel de administración

El administrador puede iniciar sesión con las siguientes credenciales:

- **Usuario:** `admin`
- **Contraseña:** `admin123`

## Funcionalidades

### Administrador

El administrador dispone de las siguientes funcionalidades:

- Gestión de productos.
- Gestión de categorías.
- Gestión de usuarios.
- Autorización de nuevos usuarios registrados.
- Auditoría de acciones, donde se registran los movimientos realizados dentro del sistema, incluyendo los intentos de inicio de sesión con credenciales incorrectas.

### Usuario

El flujo para los usuarios es el siguiente:

1. Registrarse en el sistema.
2. Esperar la autorización del administrador.
3. Iniciar sesión una vez aprobado.
4. Realizar compras dentro de la tienda.
